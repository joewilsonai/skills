# YouTube publication record

Keep one record per video ID. Start with the channel handle, exact ID or draft name, requested action, authorized fields and date. For a refresh, capture the current public title, description and thumbnail before editing. Record the release date and any later edit time separately.

| Before posting | Enter the actual evidence |
|---|---|
| Audience | Viewer’s question, one or two terms, and their source. Mark a term as editorial unless a Studio report actually shows it. |
| Promise | Selected title, unique first two description sentences, and the opening shot or line that earns the promise. |
| Cover | Selected filename, what it shows, rights and exact required credit. For a refresh, retain the old cover if available. |
| Description | Verified source URLs, any required credit, actual chapter timestamps, and a working next-watch link if useful. |
| Studio settings | Original language, caption language and track type, audience and disclosure answers, useful spelling tags and optional relevant hashtags. Record feature access for chapters, experiments or related viewing when used. |

After the authorized action, enter the URL, video ID, edit time and evidence for each surface. Use **draft**, **saved in Studio**, **observed publicly**, **unavailable**, or **not checked** as appropriate.

| Verification | What to inspect |
|---|---|
| Saved in Studio | Reopen the same video’s details. Compare the saved title, description, thumbnail, visibility, settings and captions with the requested change. Record known omissions. |
| Public watch page | Open the exact watch URL as a viewer. Check the title, opening lines, expanded credits, chapter timestamps, CC language and applicable end screen. Record whether the next-watch link and external sources are clickable. Compare the displayed cover with the selected artwork on a public thumbnail surface. Record delayed or unavailable elements separately. |
| Later outcome | Enter observation window, impressions and CTR by traffic source, first-30-second retention when available, and actual search queries reported by Studio. For A/B tests, record what differed and Studio’s watch-time-based outcome. Mark sparse data or an inconclusive test explicitly. |
